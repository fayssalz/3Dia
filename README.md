**3Dia**
3Dia is a high-fidelity, web-based 3D gemstone configurator designed for real-time visualization of diamond physics, proportions, and light behavior. It allows users to manipulate precise geometric parameters and rendering settings to see how they impact a stone's final cut grade and visual brilliance.

**✨ Key Features**
Based on the interactive dashboard, 3Dia provides granular control over:
Gemstone Physics: Adjust Refraction (RI), Dispersion, Absorption, and Color (hex-based) to simulate different gemstone varieties.
Geometric Proportions: Real-time modification of Crown height/angle, Pavilion height/angle, Girdle thickness, and Table percentage.
Cut Analysis: Automatic calculation of the Final Cut Grade based on input proportions.

**Advanced Rendering:**
Toggle between Perspective and Orthographic projections.
Control Ray Depth and post-processing effects like Bloom (threshold and intensity).
Customizable background colors and lighting environments.

**🛠️ Technical Stack**
_Engine_: Three.js / WebGL (Core 3D rendering)

_Physics_: Custom shaders for dispersion and refraction simulation.

_Frontend_: HTML5, CSS, and JavaScript.
